Overview

I designed a conversational, AI-powered chart builder to fix the #1 complaint about SafetyCulture Analytics: that building a chart was too manual and fiddly to bother with. The project reached launch-readiness — design and spec through dogfood → beta → GA — before the roadmap shifted.

The problem

Problem → Opportunity Manual, fiddly chart-building → charts created through conversation

Only ~45% of users who started building a chart actually finished it (Nov 2024 – Mar 2025). In customer calls, "the learning curve" came up repeatedly — the existing builder asked users to make a series of configuration decisions before they saw anything useful.

~45% of started charts were completed — the baseline to beat
#1 most common complaint about Analytics in customer calls

Approach

A natural-language chat interface that generates a chart instantly, then asks guided follow-up questions — metric → attribute → filters → chart type → config — only when needed. Instead of front-loading every decision, the design gives users something visual immediately and refines it through conversation.

Scope decisions

V1 was deliberately limited to one entry point: the Analytics landing page. Dashboard-level chart creation was excluded — both to avoid filter-consistency issues between dashboard and chart contexts, and to match the design capacity available. Constraining scope this way meant the core conversational flow could be properly resolved rather than spread thin.

Success metrics

  • Completion rate — lift chart completion past the existing baseline.
  • Adoption signal — track the percentage of charts created via natural language rather than the manual builder.

Outcome

The project reached launch-readiness: design and spec were complete, with a staged rollout planned (dogfood → beta → GA) — before the roadmap shifted and the release was paused.
